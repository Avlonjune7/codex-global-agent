# Design 快速入口

版本：3.6.1 · 更新：2026-11-12
用户要求与项目约束优先；沿用项目技术栈和视觉体系。

- 改法明确的文案、表单、组件及样式微调：读相关代码，复用样板、组件和主题，直接实施；无需读取完整设计规范、搜参考或启动完整设计流程。
- 新页面、整体改版、方向未定，或现有规范不足以决定组件、布局与体验时，读取 [完整规范](DESIGN.md) 的相关章节；Oil UI Pro 按具体设计问题使用。
- 复用顺序：项目组件与样板 → 已安装组件库 → 必要的最小业务组件。不重写库已提供的行为，不建立第二套主题，不因单次使用提前抽象。同类界面统一布局、间距和响应式行为；同步清理重复样式，避免叠加覆盖。
- 保留业务、权限和操作路径；覆盖受影响状态、标签、键盘焦点、长内容与窄屏，不以颜色作为唯一提示。
- 设置、配置和编辑窗口默认使用居中弹窗，不使用侧边抽屉；长内容在窗口内滚动，标题、关闭入口和底部操作区保持可见。
- 局部修改验影响区域，公共组件抽查使用页面；新页面、布局与响应式改动覆盖目标设备。查看真实画面并验证主要操作，完成项目要求的工程检查。
- 性能问题按需读 [性能细则](references/performance.md)；方向参考按需读 [设计参考](references/inspiration.md)。说明未验证范围，不以编译成功代替视觉验收。
